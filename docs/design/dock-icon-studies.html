Dock icon studies

Twelve complete icon sets for tabcomputer's dock. Every set draws the same ten glyphs from one geometry, so the apps belong together; the set changes only the material. Each is shown on the light and the dark desktop.

Pearl, Holo foil and Liquid glass are rendered live (WebGL shaders and three.js transmission) and animate only while on screen; reduced-motion pauses them. The others are SVG and CSS, so they cost nothing to ship.
