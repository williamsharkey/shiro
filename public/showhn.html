I built a browser-native Unix environment — shell, filesystem, git, npm, node, vi, 200+ commands. Everything is JavaScript running client-side with IndexedDB for persistence. The whole thing builds to a single static HTML file (~420 KB gzipped).

Try it: https://shiro.computer

For interactive demos showing npm install, node execution, and git workflows — running live in Shiro, not recordings — see https://shiro.computer/about

Source: https://github.com/williamsharkey/shiro

P.S. curl -fsSL https://claude.ai/install.sh | bash works. You can run real Claude Code and it can use Shiro's tools like a normal Linux system.

sagebird 3 hours ago | 61 points | parent | next

Update: Shiro now runs real x86-64 ELF binaries. There's a from-scratch instruction-level emulator (~130 instructions, 46 Linux syscalls, SSE2, TLS) that executes musl-static binaries compiled with gcc. No WASM translation layer — actual x86 decode-execute on every instruction, in pure TypeScript.

Try: x86 run ./hello with a real musl-static binary, or x86 debug ./hello to step through it instruction by instruction.
