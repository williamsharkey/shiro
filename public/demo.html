Build Apps in Your Browser

npm install, npm start, and see your app live — with Claude as your pair programmer. No local setup needed.

1

Initialize your project

Create a new project with npm init, just like you would locally.

$ npm init -y
# Creates package.json with defaults
2

Install dependencies

Install packages from the npm registry. Express, React, anything you need.

$ npm install express
# Downloads and installs express + dependencies
3

Write your server

Use spirit to generate code, or write it yourself with vi.

$ spirit "write an Express API with a /hello endpoint" > server.js
# Or: vi server.js
4

Start and preview

Run your app. Shiro auto-detects the port and opens a live preview pane.

$ npm start
# Server starts, split-view preview opens automatically
5

Iterate with AI

Pipe files to spirit for analysis, refactoring, or adding features.

$ cat server.js | spirit "add a /users endpoint with GET and POST"
# AI reads your code and generates the updated version
