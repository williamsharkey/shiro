Demos

Run GitHub repos instantly in your browser

Click any project below to clone, detect, and run it inside Shiro. Games become full-screen apps. CLI tools run in the terminal. No install required.

How it works

1

Visit shiro.computer/user/repo

2

Shiro clones the repo with git clone

3

Auto-detects project type (static, Node, Python, C, Lua)

4

Installs deps, builds, and runs — all in-browser
