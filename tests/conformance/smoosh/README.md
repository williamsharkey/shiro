# smoosh POSIX shell tests

`shell/` is `tests/shell` of [smoosh](https://github.com/mgree/smoosh) at
cc67dbe6a4953e51431997eac025b5e3f46c3d2d and `util/` its `tests/util` C
helpers (MIT, see LICENSE). Run by `../smoosh-posix.conf.ts`; `baseline.json`
(from `scripts/conformance/smoosh-baseline.mjs`) lists the cases host dash or
bash --posix passes, which are the ones scored.
