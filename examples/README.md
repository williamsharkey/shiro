# Shiro Examples

Runnable shell scripts demonstrating Shiro's capabilities. Paste these into [shiro.computer](https://shiro.computer) line-by-line or read them as documentation.

| Example | What it covers |
|---------|---------------|
| [hello-world.sh](hello-world.sh) | Echo, pipes, variables, basic shell |
| [file-operations.sh](file-operations.sh) | mkdir, cp, mv, find, permissions |
| [npm-project.sh](npm-project.sh) | npm init, install, require(), scripts |
| [c-compiler.sh](c-compiler.sh) | Write C, compile to WASM, run |
| [sqlite-database.sh](sqlite-database.sh) | Tables, queries, joins, aggregates |
| [python-script.sh](python-script.sh) | Python one-liners and scripts |
| [git-workflow.sh](git-workflow.sh) | init, branch, commit, diff, log |
| [web-app.sh](web-app.sh) | serve, page inspect, become mode |
| [claude-code.sh](claude-code.sh) | claude -p for code generation |
| [seed-export.sh](seed-export.sh) | Snapshot filesystem as GIF or HTML |

## Running

Each file is a shell script with comments. You can:

1. **Paste line-by-line** into the Shiro terminal
2. **Save and run** — copy to a file and `sh script.sh`
3. **Read as docs** — comments explain what each command does
